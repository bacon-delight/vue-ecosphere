# Components

Vue Ecosphere ships 24 components, grouped by purpose. Every page below includes a live demo, prop / event / slot reference, and accessibility notes.

## Call to Action

| Component | Purpose |
| --- | --- |
| [Button](/components/button) | Trigger an action |
| [Link](/components/link) | Navigate, optionally styled like a button |

## Data Entry

| Component | Purpose |
| --- | --- |
| [Checkbox](/components/checkbox) | Boolean or tri-state input |
| [CheckboxGroup](/components/checkbox-group) | Multi-select from a list |
| [ChoiceChips](/components/choice-chips) | Compact single/multi select |
| [ColorPicker](/components/color-picker) | Pick a color with presets |
| [Input](/components/input) | Single-line text |
| [InputNumber](/components/input-number) | Numeric input with stepper |
| [Radio](/components/radio) | Single radio button |
| [RadioGroup](/components/radio-group) | Single-select from a list |
| [Select](/components/select) | Dropdown select (single, multi, searchable, tags) |
| [Switch](/components/switch) | Boolean toggle |
| [Textarea](/components/textarea) | Multi-line text |

## Miscellaneous

| Component | Purpose |
| --- | --- |
| [Avatar](/components/avatar) | User / entity image with status |
| [AvatarGroup](/components/avatar-group) | Stacked avatars with overflow |
| [Stepper](/components/stepper) | Multi-step progress |
| [Tag](/components/tag) | Status pill / chip |

## Navigation

| Component | Purpose |
| --- | --- |
| [Breadcrumb](/components/breadcrumb) | Hierarchical trail |

## General

| Component | Purpose |
| --- | --- |
| [Icon](/components/icon) | SVG icon wrapper |

::: tip
Every `Ep*` component is registered globally when you use the plugin. You can also import them by name from `vue-ecosphere`.
